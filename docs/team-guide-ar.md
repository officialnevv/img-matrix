## 1. الصورة الكبيرة في دقيقة

1. الصورة عبارة عن جدول أرقام (مصفوفة). كل رقم بيقول النقطة الصغيرة دي (البكسل) سطوعها قد إيه، من 0 (أسود) لـ 255 (أبيض).
2. الصورة الملونة فيها 3 جداول فوق بعض: أحمر (R) وأخضر (G) وأزرق (B).
3. البرنامج بيحمّل الصورة في الجداول دي، يعمل عليها شوية جبر خطي، وبعدين يحوّل الجداول الجديدة لصورة تاني.

المشروع كله في 4 جمل تقدر تقولهم للدكتور:

> "قرأنا الصورة كمصفوفة باستخدام Python و NumPy. كل عملية هي عملية على المصفوفات: تحويل الرمادي هو مجموع موزون لمصفوفات R وG وB، وتغيير السطوع هو جمع مصفوفة ثابتة مع القص (clipping)، وقلب الصورة هو الضرب في مصفوفة التبديل (exchange matrix)، والأبيض والأسود هو مقارنة كل عنصر بحد معين (threshold). بعد كده بنعرض ونحفظ الصورة الأصلية والناتجة، وكمان نشرنا المشروع كموقع على الإنترنت."

## 2. كورس سريع في Python و NumPy (اللي بنستخدمه بس)

### 2.1 أساسيات Python

| اللي بتشوفه | معناه |
| --- | --- |
| `x = 5` | خزّن القيمة 5 في صندوق اسمه x. |
| `# كلام` | تعليق. الكمبيوتر بيتجاهله، ده ملاحظة للبشر. |
| `"hello"` | نص (string). |
| `import numpy as np` | هات مجموعة أدوات اسمها NumPy وسمّيها `np` اختصارًا. |
| `def name(a, b):` | عرّف دالة (function): وصفة بتاخد مدخلات a وb وترجّع نتيجة. |
| `return x` | إجابة الدالة. |
| `if ...:` / `else:` | اعمل حاجة بس لو الشرط متحقق. |

بايثون بتستخدم **المسافات في أول السطر (indentation)** عشان تعرف إيه اللي جوه الدالة أو جوه الـ if.

### 2.2 NumPy: الـ array هو المصفوفة

NumPy مكتبة بتشتغل على مصفوفات كاملة مرة واحدة. نوع المصفوفة فيها اسمه **array**.

```python
A = np.array([[10, 20, 30],
              [40, 50, 60]])
```

دي مصفوفة 2 صف و3 أعمدة.

| الكود | معناه |
| --- | --- |
| `A.shape` | الحجم: (2, 3) يعني 2 صف و3 أعمدة. الصورة الملونة شكلها (H, W, 3): الارتفاع، العرض، 3 ألوان. |
| `A[0, 1]` | العنصر في الصف 0 والعمود 1 (بايثون بتعد من صفر)، يعني 20. |
| `A[:, 0]` | العمود الأول كله. علامة `:` معناها "الكل". |
| `A + 50` | بيضيف 50 لكل عنصر مرة واحدة. من غير loop. |
| `A >= 30` | مصفوفة True/False: هل كل عنصر أكبر من أو يساوي 30؟ |
| `A[:, ::-1]` | كل الصفوف، والأعمدة بالعكس. ده بيقلب المصفوفة يمين وشمال. |

**شرح `[:, ::-1]`:** جوه الأقواس، اللي قبل الفاصلة للصفوف واللي بعدها للأعمدة. `:` للصفوف يعني كل الصفوف. و`::-1` للأعمدة يعني "من الأول للآخر بخطوة رجوع 1"، فالأعمدة بتطلع معكوسة.

### 2.3 أنواع البيانات (ليه بنكتب `astype`)

الصور بتخزّن كل رقم في 8 بت، واسمه `uint8` (عدد صحيح موجب 8 بت)، ومينفعش يشيل غير من 0 لـ 255. لو جمعت 50 على 240 في `uint8` الناتج بيلف ويبقى 34 بدل 290. عشان كده قبل الحسابات بنحوّل لنوع أكبر بـ `.astype(...)`:

- `float64`: أرقام عشرية (للرمادي، لأن الأوزان عشرية).
- `int16`: أعداد صحيحة أكبر وتقبل السالب (للسطوع).

وبعد الحساب بنرجّع بـ `.astype(np.uint8)` عشان الأرقام تبقى قيم بكسل صحيحة.

### 2.4 أربع دوال في NumPy لازم تعرفهم

| الدالة | بتعمل إيه | مثال |
| --- | --- | --- |
| `@` | ضرب مصفوفات / ضرب نقطي. | `rgb @ w` |
| `np.clip(x, 0, 255)` | بتجبر كل القيم تفضل بين 0 و255 (الأكبر يبقى 255 والأصغر يبقى 0). | clip(290) = 255 |
| `np.where(cond, a, b)` | لكل عنصر: لو الشرط صح خد a، غير كده خد b. | `np.where(g >= 128, 255, 0)` |
| `np.rint(x)` | بتقرّب لأقرب عدد صحيح. | rint(124.2) = 124 |

### 4.2 `load_image`: قراءة الصورة

```python
def load_image(file, max_side=1200):
    img = Image.open(file).convert("RGB")
    img.thumbnail((max_side, max_side))
    return np.asarray(img, dtype=np.uint8)
```

- `Image.open(file)` بتفتح الصورة من الجهاز.
- `.convert("RGB")` بتجبر الصورة تبقى 3 قنوات لون، حتى لو الأصل PNG شفاف أو رمادي.
- `thumbnail(...)` بتصغّر الصور الكبيرة جدًا بحيث أطول ضلع ميزيدش عن 1200 بكسل، عشان البرنامج يفضل سريع.
- `np.asarray(...)` بتحوّل الصورة لـ NumPy array: المصفوفة. **ده اللحظة اللي الصورة بتبقى فيها أرقام.**

**قول للدكتور:** "هذه الدالة تقرأ ملف الصورة وتحوله إلى مصفوفة من الأعداد الصحيحة من 0 إلى 255 بحجم ارتفاع في عرض في 3."

### 4.3 `to_grayscale`: من ملون لرمادي

```python
def to_grayscale(rgb):
    weights = np.array([0.299, 0.587, 0.114])
    return np.rint(rgb.astype(np.float64) @ weights).astype(np.uint8)
```

الرياضيات: Gray = 0.299·R + 0.587·G + 0.114·B.

سطر سطر:

1. `weights` هو المتجه (0.299, 0.587, 0.114).
2. `rgb.astype(np.float64)` بتحول لأرقام عشرية عشان مفيش تقريب بدري.
3. `@ weights` بتضرب (R, G, B) بتاع كل بكسل في الأوزان وتجمع: ضرب نقطي (dot product) لكل بكسل. مصفوفة H × W × 3 مضروبة في متجه من 3 عناصر بتدّي مصفوفة H × W، وهي الصورة الرمادية.
4. `np.rint` بتقرّب لأعداد صحيحة، و`.astype(np.uint8)` بترجّع لنوع البكسل الصحيح.

**ليه الأوزان مش متساوية؟** عين الإنسان أحسّ حاجة بالأخضر وأقل حاجة بالأزرق، فالأخضر وزنه الأكبر. ومجموع الأوزان 1، فالنتيجة عمرها ما بتعدي 255.

**مثال:** البكسل (200, 100, 50) بيدّي 59.8 + 58.7 + 5.7 = 124.2، يتقرّب لـ 124.

### 4.4 `adjust_brightness`: السطوع

```python
def adjust_brightness(img, beta):
    return np.clip(img.astype(np.int16) + int(beta), 0, 255).astype(np.uint8)
```

الرياضيات: I' = clip(I + β, 0, 255). إضافة β لكل عنصر هي نفسها إضافة β في مصفوفة كلها واحدات.

1. `astype(np.int16)`: نستخدم أرقام أكبر عشان 240 + 50 ميلفّش ويبقى 34.
2. `+ int(beta)`: بنضيف β لكل بكسل. β موجب بيفتّح الصورة، وسالب بيغمّقها.
3. `np.clip(..., 0, 255)`: أي حاجة فوق 255 تبقى 255، وأي حاجة تحت 0 تبقى 0.
4. `astype(np.uint8)`: نرجع لنوع البكسل.

**مثال (β = 50):** 100 ← 150. و240 ← 290 ← تتقص لـ 255.

### 4.5 `flip_horizontal` و`flip_horizontal_matrix`: القلب الأفقي

```python
def flip_horizontal(img):
    return img[:, ::-1]
```

بتعكس ترتيب الأعمدة: صورة المرآة.

النسخة بالجبر الخطي:

```python
def flip_horizontal_matrix(img):
    J = np.eye(img.shape[1])[::-1]
    if img.ndim == 3:
        out = np.einsum("hwc,wv->hvc", img.astype(np.float64), J)
    else:
        out = img @ J
    return np.rint(out).astype(np.uint8)
```

- `np.eye(n)` بتعمل مصفوفة الوحدة n × n.
- `[::-1]` بتعكس صفوفها، فتبقى J، **مصفوفة التبديل (exchange matrix)**: واحدات على القطر الثانوي (anti-diagonal).
- ضرب الصورة من اليمين في J بيعكس أعمدتها: I' = I · J.
- `np.einsum(...)` مجرد طريقة تقول "اضرب كل طبقة لون من التلاتة في J". تقدر تقول عنها: "ضرب مصفوفات مطبق على كل مصفوفة من مصفوفات الألوان التلاتة".

لصورة عدد أعمدتها 3، مصفوفة J تبقى:

```
| 0 0 1 |
| 0 1 0 |
| 1 0 0 |
```

و\[10 20 30\] · J = \[30 20 10\].

**ليه في نسختين؟** نسخة الـ slicing أسرع وأبسط، ونسخة J بتوضح الجبر الخطي. اختبرنا إن الاتنين بيدّوا نفس الصورة بالظبط. معلومة حلوة: J · J = I، فلو قلبت مرتين ترجع الصورة الأصلية.

### 4.6 `to_black_white`: الأبيض والأسود

```python
def to_black_white(rgb, threshold=128):
    return np.where(to_grayscale(rgb) >= threshold, 255, 0).astype(np.uint8)
```

الرياضيات: B(i,j) = 255 لو Gray(i,j) ≥ T، غير كده 0.

1. `to_grayscale(rgb)` بتعمل مصفوفة الرمادي الأول.
2. `>= threshold` بتعمل مصفوفة True/False: هل كل بكسل سطوعه على الأقل T؟
3. `np.where(cond, 255, 0)`: مكان الـ True حط 255 (أبيض)، ومكان الـ False حط 0 (أسود).

`threshold=128` قيمة افتراضية: لو محدش حدد T، بتستخدم 128، نص المدى من 0 لـ 255. لو T أصغر بتطلع صورة أبيض أكتر، ولو أكبر بتطلع أسود أكتر.

## 5. `run_local`: البرنامج اللي بيشتغل على جهازك

بتشغله كده:

```
python app.py path/to/image.jpg 50 128
```

التلات حاجات اللي بعد `python app.py` هما: مسار الصورة، وقيمة السطوع β (50)، والـ threshold وهو T (128). ولو متكتبش حاجة بعد `python app.py` بيشغّل الموقع بدل البرنامج المحلي. اللي بتعمله `run_local` بالترتيب:

4. بتعمل فولدر `output`، وبـ Matplotlib بترسم كل الصور في صف واحد (الأصلية والنتايج جنب بعض)، وبتحفظ كل صورة PNG ومعاها `comparison.png`.

## 8. أسئلة ممكن الدكتور يسألها (مع الإجابات)

الإجابات مكتوبة بصياغة بسيطة تقدر تقولها للدكتور.

**س1. إيه هي الصورة الرقمية رياضيًا؟** مصفوفة من الأعداد. الرمادية مصفوفة واحدة H × W، والملونة تلات مصفوفات (R وG وB) يعني H × W × 3، وقيم عناصرها من 0 لـ 255.

**س2. إزاي قرأتوا الصورة؟** بمكتبة Pillow باستخدام `Image.open`، وبعدين `np.asarray` بتحولها لمصفوفة NumPy.

**س3. ليه أوزان الرمادي مش متساوية (1/3 لكل لون)؟** لأن عين الإنسان أكثر حساسية للأخضر، وبعده الأحمر، وأقل حساسية للأزرق. فاستخدمنا 0.299 و0.587 و0.114. ومجموعهم 1 عشان النتيجة تفضل بين 0 و255.

**س4. تحويل الرمادي هو أنهي عملية في الجبر الخطي؟** ضرب نقطي (ضرب مصفوفة في متجه) بين متجه ألوان كل بكسل ومتجه الأوزان.

**س5. ليه بتحولوا لـ `int16` أو `float64` قبل الحساب؟** البكسلات متخزنة بنوع `uint8` (من 0 لـ 255). الجمع أو الضرب ممكن يطلع برّه المدى ده ويلف من أوله (240 + 50 تبقى 34). النوع الأكبر بيحافظ على القيمة الحقيقية، وبعدين نقص القيم ونرجّع النوع الأصلي.

**س6. الـ `clip` بتعمل إيه وليه محتاجينها؟** بتجبر القيم تفضل بين 0 و255. من غيرها القيم الأكبر من الأبيض أو الأصغر من الأسود تبقى غير صالحة وتلف وتطلع ألوان غلط.

**س7. تغيير السطوع هو أنهي عملية على المصفوفات؟** جمع قيمة ثابتة على كل العناصر: I + βE، حيث E مصفوفة كلها واحدات، وبعدها clipping.

**س8. القلب الأفقي عملية مصفوفات إزاي؟** ضرب الصورة من اليمين في مصفوفة التبديل J (واحدات على القطر الثانوي): I' = I · J. وده بيعكس ترتيب الأعمدة.

**س9. لو قلبنا الصورة مرتين نرجع للأصل؟** أيوه، لأن J · J = I، يعني (I · J) · J = I.

**س10. إيه الفرق بين الضرب في J من اليمين ومن الشمال؟** من اليمين (I · J) بيعكس الأعمدة، وده القلب الأفقي. ومن الشمال (J · I) بيعكس الصفوف، وده القلب الرأسي.

**س11. الأبيض والأسود بيشتغل إزاي، والـ threshold إيه؟** بنعمل مصفوفة الرمادي، وكل بكسل قيمته أكبر من أو تساوي T بيبقى 255، وغير كده بيبقى 0. القيمة T = 128 هي نص المدى، ولما نغيّرها بتتغيّر نسبة الأبيض في الصورة.

**س12. ليه بنحول لرمادي قبل الأبيض والأسود؟** لأن المقارنة بالـ threshold محتاجة رقم واحد لكل بكسل، والبكسل الملون فيه تلاتة.

**س13. ليه NumPy وليس loops عادية؟** لأن NumPy بتطبق العملية على ملايين العناصر مرة واحدة، فهي أسرع بكتير والكود أقصر وشبه المعادلات.

**س14. الأبيض والأسود هو نفسه الرمادي؟** لأ. الرمادي فيه 256 درجة (من 0 لـ 255)، والأبيض والأسود فيه قيمتين بس (0 و255).

**س15. شكل (shape) مصفوفة الصورة إيه؟** الملونة: (الارتفاع، العرض، 3). الرمادية أو الأبيض والأسود: (الارتفاع، العرض).

**س16. المشروع ده له علاقة بالذكاء الاصطناعي إزاي؟** نماذج الرؤية بالكمبيوتر بتستقبل الصور على شكل مصفوفات. والمعالجة المبدئية زي تحويل الرمادي وتغيير السطوع والقلب بتتعمل كتير قبل التدريب أو التعرّف. والقلب كمان بيُستخدم لتوليد صور إضافية للتدريب (data augmentation).

**س17. بتشغلوا المشروع إزاي؟** `python app.py image.jpg 50 128` بيشغّل البرنامج المحلي. و`python app.py` من غير حاجة بعده بيشغّل الموقع، أو تفتح الموقع المنشور وترفع صورة وتختار العملية.

**س18. إيه استخدام GitHub و Vercel هنا؟** GitHub بيخزّن الكود، وVercel بينشر نسخة الويب مباشرة منه.

## 9. تمرين قبل المناقشة

1. كل واحد يشغّل `python main.py` على جهازه مرة بصورته هو، ويغيّر β وT ويشوف الفرق.
2. كل واحد يختار عملية ويتدرب يشرحها في دقيقة: المعادلة، ثم مثال رقمي بقيم بكسلات صغيرة، ثم السطور اللي بتنفذها في الكود.
